Daily Word Hunt is built for calm screen play, but paper and larger type are first-class too.

## Print today’s puzzle

1. Open [Print](/print).
2. Use your browser print dialog (**Cmd/Ctrl + P**).
3. Game chrome (timer, buttons) is hidden in print CSS where possible.

Tip: choose “background graphics” if your browser strips letter cell colors and you want them.

## Large print on screen

- Use the **Large print** checkbox under the puzzle, or  
- Open the home page with large print enabled from the same tools row.

Large print increases letter size and slightly eases spacing — useful for shared devices and low vision.

## Classroom / table use

Print works well as a quiet starter activity. Words are general everyday vocabulary in the default daily pool — not branded media franchises.

## Feedback

If print margins look wrong on a specific browser, note the device and browser version when you report it later — print CSS varies a lot.
